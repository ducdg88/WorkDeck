# WorkDeck

**Stop juggling ten browser tabs of AI tools → open one desktop workspace that holds every one of them.**

An Electron desktop app that gathers a solo founder's AI tools and web apps into one workspace.

**Thôi mở mười tab trình duyệt cho mười công cụ AI → mở một bàn làm việc trên máy tính chứa tất cả.**

App desktop viết bằng Electron, gom các công cụ AI và web app của người làm một mình về một màn hình.
